# Cricket Data Processing Documentation

## 1. Aggregate Points Processing (`aggregate_points.py`)
Extracts career-level performance statistics from the CricketStats library for T20, ODI, and Test formats. Processes data from January 1, 2010 to May 31, 2026. Generates aggregated metrics used as baseline performance indicators for fantasy calculations. Outputs internal aggregated datasets that feed into downstream fantasy points computation.

## 2. Data Extraction (`Data_Extracter.py`)
Retrieves detailed match and player data from CricketStats across all formats (T20, ODI, Test). Enhanced with additional features including Maiden Overs, Fours, Sixes, Bowled dismissals, and LBW dismissals. Operates on date range January 1, 2010 to May 31, 2026. Saves extracted data as CSV files in `../data/raw/` directory for further processing.

## 3. Match Level Squad Generation (`Match_level_players.py`)
Creates two distinct squad data formats for different application needs:
- **MatchID-wise Squads**: Structured for model user interface consumption
- **Date-wise Hierarchical Squads**: Organized for frontend use with temporal hierarchy
Includes automatic second squad generation based on players from the last 10 matches of same format and gender. Date range: January 1, 2010 to present. Outputs saved to `data/processed/combined_squad.json` (MatchID-wise) and `data/processed/datewise_squad.json` (Date-wise).

## 4. Data Formatting for Fantasy (`Json_Formatter.py`)
Transforms raw CSV data into hierarchical JSON structure optimized for fantasy points calculation. Converts data to format: `{Player: {MatchID: {stat: value, ...}}}`. For Test matches, computes aggregate Batting Strike Rate and Bowling Average across innings. Performs one-hot encoding on dismissal types ("How Out" feature). Adds critical fantasy-relevant metrics: Innings-wise Runs and Innings-wise Wickets. Processes data spanning January 1, 2010 to May 31, 2026.

## 5. Fantasy Points Calculation (`testing.py`)
Computes fantasy points for player performances across all formats (T20, ODI, Test). Utilizes processed JSON data from Json_Formatter.py and aggregate statistics. Applies format-specific scoring rules covering batting (runs, strike rate, boundaries), bowling (wickets, economy, maidens), and fielding (catches, stumpings). Generates three output files:
- `player_fantasy_points_t20.json`
- `player_fantasy_points_odi.json`
- `player_fantasy_points_test.json`
Operates on date range January 1, 2010 to May 31, 2026.

## 6. Player Role Classification (`player_roles.py` / `executed_player_roles.py`)
Assigns categorical roles to players based on career statistical thresholds:
- **Wicketkeeper (WK)**: Minimum 5 career stumpings
- **Batter (BAT)**: 200+ matches, 5000+ runs, <150 wickets
- **All-Rounder (AR)**: 200+ matches, 4000+ runs, 200+ wickets
- **Bowler (BOWL)**: 200+ matches, 200+ wickets, <2500 runs
- **Other/Unknown (IDK)**: Players not meeting any role criteria
Uses statistics generated by `create_player_stats_csv.py` and formatted data from `Json_Formatter.py`. Date range: January 1, 2010 to present.

## 7. Player Statistics Aggregation (`create_player_stats_csv.py`)
Creates consolidated player statistics CSV from available JSON match data. Processes data for period January 1, 2010 to present. Generates `all_player_stats.csv` containing:
- Player name
- Career total runs
- Career total wickets
- Career total stumpings
- Career total matches served
Serves as primary input for player role classification algorithms. Output saved to `data/interim/all_player_stats.csv`.
