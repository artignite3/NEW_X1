# Active data processing

[`data_download.py`](data_download.py) obtains source archives; [`cricsheet_ingestor.py`](cricsheet_ingestor.py) derives dated fantasy/statistical records; [`incremental_feature_append.py`](incremental_feature_append.py) updates feature tables; [`feature_engineering.py`](feature_engineering.py) contains transformations. [`safe_publish.py`](safe_publish.py) atomically promotes validated outputs with a last-good copy, and [`seed_backups.py`](seed_backups.py) creates missing verified local backups. [`live_data_sync.py`](live_data_sync.py) supports a separate live-data path.

[`run_daily_sync.py`](../run_daily_sync.py) orchestrates the active historical and optional fixture stages. It needs installed Python packages, source archive access, and provider keys for full future-feed coverage; set `NEW_X1_DATA_ROOT` for another data directory. Do not delete manifests, last-good files or model archives as routine cleanup. Run `python -m unittest tests.test_pipeline tests.test_leakage tests.test_resilience_and_explanations -v` from the root. The [manual legacy preparation](../data_preprocessing/README.md) is distinct from this pipeline; see the [runbook](../docs/RUNBOOK.md).
