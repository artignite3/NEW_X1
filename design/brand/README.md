# NEW_X1 brand assets

Created 8 October 2026 with the built-in image generation tool. The crossed cricket bats form an X, with a cricket ball in the upper-right space. Orange and off-white match the application's existing charcoal palette. This is raster artwork, not an editable vector logo.

## Files

- `frontend/public/brand/new-x1-logo.png`: original transparent logo, 1254 × 1254.
- `design/brand/new-x1-icon-master.png`: generated charcoal-background app icon master, 1254 × 1254.
- `frontend/public/brand/new-x1-app-icon.png`: 512 × 512 app icon.
- `frontend/public/brand/new-x1-nav-icon.png`: 128 × 128 navigation asset, displayed at 32 × 32 beside the existing NEW_X1 wordmark.
- `frontend/src/app/favicon.ico`: 16, 24, 32, 48 and 64px frames.
- `frontend/src/app/icon.png`: 512 × 512 PNG icon.
- `frontend/src/app/apple-icon.png`: 180 × 180 Apple touch icon.

Next.js discovers the app-directory icons and inserts the appropriate metadata links automatically. The dark icon background keeps the off-white bat visible in both light and dark browser chrome. Artwork generation and creative editing used image_gen; Pillow was used only to export output sizes and ICO/PNG formats. No deployment code was resumed for this branding change.

## Generation prompt

Use case: logo-brand. Asset type: final logo emblem and favicon master for NEW_X1, a cricket performance intelligence application. Create one original polished minimalist sports-tech brand mark, centered on a square transparent canvas, occupying about 82% of the canvas with comfortable symmetric margins. The mark is a bold compact geometric X made from two crossed abstract cricket bats: one vivid orange #f0561d diagonal and one off-white #ececea diagonal. Cricket bat shape should be suggested by a broad clean tapered blade and short handle, not detailed realistic equipment. Add one solid orange cricket ball, modestly sized, tucked into the upper-right negative space without touching the bats. Make the crossed bats feel purposeful and forward-moving, with carefully balanced negative space and strong silhouette. The logo will appear on a charcoal #0b0b0c app and inside a charcoal favicon tile. Flat clean vector-like graphic, exceptional professional proportions, sharp consistent edges, visually distinctive, legible at 16px. Genuine transparent background; only the mark itself, no background tile. No lettering, no words, no tiny lines or seams, no charts, no shield, no gradients, no glows, no texture, no 3D, no drop shadow, no mockup, no watermark, no multiple alternatives.
