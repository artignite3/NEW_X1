# Model and API

[`model_fastapi.py`](model_fastapi.py) is the public FastAPI entry point. It validates requests via [`api_schemas.py`](api_schemas.py), checks Supabase sessions with [`auth.py`](auth.py), stores user-owned analyses through [`user_store.py`](user_store.py), and calls [`team_generator.py`](team_generator.py). The generator resolves names, builds a dated player pool, requests T20 or ODI/Test predictions from [`predict_model.py`](predict_model.py), applies optional intelligence, optimizes with PuLP, and checks the result with [`squad_validator.py`](squad_validator.py). `explanation_snapshot.py` holds short-lived explanation inputs. `data_contract.py` fixes the feature schema and training cutoff.

`train_model.py`, `evaluate.py`, and `tune_optimizer_config.py` are explicit offline operations; startup does not retrain. The `calculator_*` files hold format scoring. `model.py`, `squads_fastapi.py`, `aggregate_stats_fastapi.py` and `llm_inference.py` contain older or supporting interfaces; the deployed launcher targets `model.model_fastapi:app`. Do not load untrusted joblib artifacts. Set `NEW_X1_MODEL_ROOT` and `NEW_X1_DATA_ROOT` when artifacts live outside this checkout; deployed auth also needs `APP_ENV` and Supabase variables.

From the repository root, run `python -m uvicorn model.model_fastapi:app --host 127.0.0.1 --port 8000` after installing dependencies and restoring artifacts. Run `python -m unittest discover -s tests -p 'test_*.py' -v` for the contract, scoring, leakage, resilience, auth and API tests. See the [API reference](../docs/API_REFERENCE.md), [architecture](../docs/ARCHITECTURE.md) and [root setup](../README.md).
